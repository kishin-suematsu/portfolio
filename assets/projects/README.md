## 推奨スペック

- **画像**: 1200×1500px (4:5 縦長), PNG/JPG, ~300KB以下
- **動画**: 1080×1350px (4:5 縦長), MP4 H.264, ミュート/ループ前提, 5-15秒, ~3MB以下
- 動画は自動再生・ミュート・ループされます (`autoplay muted loop playsInline`)
- どちらも `object-fit: cover` で表示されるので、被写体を中央に
